# Lista-de-exercicios

## Sobre o Projeto

Este projeto reúne uma série de exercícios e pequenos projetos práticos desenvolvidos com HTML e CSS. O foco principal deste repositório é consolidar o aprendizado em desenvolvimento front-end por meio da experimentação contínua de diferentes estilos, layouts e abordagens visuais.

A proposta foi construir múltiplos desafios independentes, permitindo explorar desde componentes isolados até estruturas de páginas completas, testando variadas combinações de design e design patterns na web.

---

## Funcionalidades

* Coleção com diversos projetos e exercícios práticos de desenvolvimento.
* Exploração de uma grande variedade de layouts e composições visuais.
* Estruturação individual de cada desafio utilizando HTML semântico.
* Estilização diversificada com CSS para experimentar diferentes estéticas e designs.
* Organização modularizada, onde cada exercício possui seu próprio contexto de desenvolvimento.

---

## Tecnologias Utilizadas

* **HTML5**
* **CSS3**

---

## Objetivo

O principal objetivo deste projeto é servir como um portfólio de treinamento prático, documentando a evolução na escrita de código, na resolução de problemas de layout e na aplicação criativa de estilos utilizando CSS e HTML.

---

## Aprendizados

Durante o desenvolvimento deste projeto, foram aplicados conceitos como:

* Criação de layouts diversificados com abordagens tradicionais e modernas.
* Modularização de componentes e aplicação de diferentes estilos CSS.
* Organização lógica de arquivos e pastas para múltiplos projetos no mesmo repositório.
* Resolução de desafios de alinhamento, tipografia e espaçamento.
* Boas práticas de estruturação e semântica no desenvolvimento front-end.

---

## Como Executar

1. Clone este repositório:
```bash
git clone [https://github.com/seu-usuario/Lista-de-exercicios.git](https://github.com/seu-usuario/Lista-de-exercicios.git)
```

2. Acesse a pasta do projeto:

```bash
cd Lista-de-exercicios
```

3. Navegue até a pasta do exercício desejado e abra o arquivo HTML correspondente em seu navegador.
